# Crit 1 reflection

This was my first time setting up a Claude Code environment and actually
trying out a coding agent on a real project, and it was more revolutionary
than I expected. Tasks that used to take me days when I first got into web
dev got knocked out in a few minutes. That's mind-blowing, and honestly a
little scary too — I still only know a small amount of web programming, yet
I was able to build a big, multi-page site in one sitting.

The breakthrough moment came when I tried to make the "sent mail" feature
feel real: I wanted sending a message to actually save it into the Sent tab.
I couldn't get it to work, and realised why — without JavaScript or a
backend server, there's no way to save state on the client side. The page
can look convincing, but it can't remember anything between page loads on
its own. That's the moment "no JavaScript" stopped being an abstract rule on
a spec page and became something I could actually feel pushing back against
the design.

That's changed what I want to build next. I'm still adapting to how fast
this is all moving, but I think the developer I want to be is one who treats
creativity — knowing what to build and why, and understanding the
constraints well enough to know when a feature genuinely needs JavaScript or
a backend versus when it can be faked — as the real skill now, more than
knowing every syntax detail myself. I'm genuinely hyped to see what I get to
build next.
